# Social Platform / AutoTool v2

Campaign-centric UI prototype for a social automation control plane.

## Included screens

- Dashboard overview
- Campaign management
- Five-step campaign wizard
- Accounts & profiles
- AI profiles and prompts
- Content library
- Scheduler
- Queue
- Audit logs
- Analytics
- Settings

## Run

npm install
npm run dev

## Build

npm run build

The current version is a functional front-end prototype. Browser automation, AI gateway, persistence, and extension runtime are planned for the next implementation phases.
